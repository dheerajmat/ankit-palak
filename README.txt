ANKIT & PALAK — WEDDING INVITATION WEBSITE

HOW TO PREVIEW
1. Extract this ZIP file.
2. Keep index.html and the assets folder together.
3. Open index.html in Chrome or another modern browser.

WHAT IS INCLUDED
- Pastel ivory/blush/gold visual style
- Animated HTML/CSS envelope, dori cords, tassels and seal
- Hero palace background image
- Event illustration crops for the supplied wedding schedule
- Venue concept imagery for Hotel Grand Xenia and Bravia Hotel
- Decorative floral, monogram and ornamental assets
- Countdown, calendar reminder, Google Maps search links and front-end RSVP preview
- Optional Three.js ambient particles (CDN internet connection required)

IMPORTANT
- Background music is intentionally not included yet, as requested.
- Couple photos are left for a later step.
- The hotel visuals are AI-generated concept art, not verified photographs of the actual venues.
- The RSVP form is a front-end preview only and does not submit data to a server.
- Google Fonts and Three.js are loaded from external CDNs, so those features require internet access.
- Keep the assets folder beside index.html; the website uses relative image paths.
